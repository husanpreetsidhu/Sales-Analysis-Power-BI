# 📊 Sales Analysis Dashboard (2020–2022) | Power BI

## 📌 Project Overview

This project focuses on analyzing sales performance over the period 2020–2022 using Microsoft Power BI. An interactive dashboard has been developed to provide insights into sales, profit, quantity, order numbers, product categories, brands, and geographical sales distribution.

The dashboard helps understand business performance through visualizations and interactive filters, making it easier to explore sales trends and identify important business insights.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Monitor total sales, profit, quantity, and order numbers.
- Understand sales distribution across different product categories.
- Compare sales performance across different brands.
- Explore geographical sales distribution across states.
- Provide an interactive dashboard for business analysis.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
The dashboard includes important business metrics such as:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Total Cost

### 2. Category-wise Sales Analysis
A clustered column chart is used to analyze sales performance across different product categories.

### 3. Brand-wise Sales Analysis
A pie chart provides a visual representation of sales distribution across different brands.

### 4. Geographical Sales Analysis
A map visualization displays sales distribution across different states, helping explore regional sales performance.

### 5. Interactive Filtering
The dashboard includes an interactive slicer to filter and explore the data based on supervisor information.
